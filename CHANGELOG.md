# 📋 История изменений

## [1.1.0] - 2026-10-22

### 🌐 Автоматические курсы валют

#### Добавлено:
- **CoinGecko API интеграция** - автоматическое получение актуального курса TON/RUB
- **Новый модуль `utils/rates.py`** - сервис для работы с курсами валют
- **Обновленный калькулятор** - использует актуальные курсы в реальном времени
- **Комиссия Fragment** - добавлен учет 5% комиссии при конвертации через Fragment
- **Детальный расчет** - пользователи видят полный breakdown расчета стоимости

#### Изменено:
- **Алгоритм расчета** - теперь 5 шагов вместо 3:
  1. Комиссия Telegram (7%)
  2. Комиссия Fragment (5%)
  3. Stars → GRAM конвертация
  4. GRAM → RUB с актуальным курсом
  5. Вычет прибыли бота
- **Комиссии фиксированы** - Telegram 7%, Fragment 5% (не настраиваются)
- **Курс Stars → GRAM** - зафиксирован 0.01 (константа Telegram)

#### Улучшено:
- **Сообщения расчета** - добавлен индикатор "⏳ Получаем актуальный курс TON..."
- **Детальная информация** - показывается каждый шаг расчета
- **Резервное значение** - если API недоступен, используется 100 RUB/TON
- **Логирование** - все запросы к API логируются

#### Документация:
- **RATES_API.md** - полное описание работы с API и расчетами
- **QUICKSTART.md** - быстрый старт для новых пользователей
- **README.md** - обновлен с новой информацией
- **requirements.txt** - добавлена зависимость `aiohttp`

### Примеры использования:

#### До (ручные курсы):
```python
# Настройки в админке
gram_to_rub = 100  # ручной ввод
stars_to_gram = 0.01  # ручной ввод
telegram_commission = 5%  # настраивался вручную
```

#### После (автоматические курсы):
```python
# Получение через API
ton_rate = await RatesService.get_ton_to_rub_rate()
# Фиксированные константы
telegram_fee = 7%  # официальная комиссия
fragment_fee = 5%  # официальная комиссия
stars_to_gram = 0.01  # константа Telegram
```

### Миграция:

Для существующих пользователей:
1. Обновите зависимости: `pip install -r requirements.txt`
2. Перезапустите бота: `python bot.py`
3. Настройки курсов в админке больше не требуются
4. Все расчеты будут использовать актуальные курсы автоматически
