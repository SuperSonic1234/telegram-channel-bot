1. Подключитесь к серверу через SSH:

   ssh -p 58595 root@132.243.194.9
   
   Пароль: YOUR_SERVER_PASSWORD

-------------------------------------------

2. Клонируйте репозиторий:

cd /root
git clone https://github.com/SuperSonic1234/telegram-channel-bot.git
cd telegram-channel-bot

-------------------------------------------

3. Создайте виртуальное окружение и установите зависимости:

python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

-------------------------------------------

4. Создайте .env файл:

cat > .env << 'ENVEOF'
BOT_TOKEN=YOUR_BOT_TOKEN
ADMIN_ID=970377911
DATABASE_PATH=data/bot.db
ENVEOF

chmod 600 .env
mkdir -p data

-------------------------------------------

5. Проверьте что бот запускается:

python bot.py

Должно появиться:
  INFO - Бот запущен!
  INFO - Start polling
  
Если всё ок, нажмите Ctrl+C

-------------------------------------------

6. Настройте автозапуск через systemd:

cat > /etc/systemd/system/telegram-bot.service << 'SERVICEEOF'
[Unit]
Description=Telegram Channel Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/telegram-channel-bot
Environment="PATH=/root/telegram-channel-bot/.venv/bin"
ExecStart=/root/telegram-channel-bot/.venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
SERVICEEOF

-------------------------------------------

7. Запустите сервис:

systemctl daemon-reload
systemctl enable telegram-bot
systemctl start telegram-bot

-------------------------------------------

8. Проверьте статус:

systemctl status telegram-bot

Должно быть: Active: active (running)

-------------------------------------------

9. Посмотрите логи:

journalctl -u telegram-bot -f

Нажмите Ctrl+C для выхода
