# 🚀 Быстрый старт

## ⚡ За 3 минуты до запуска

### 1️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

Установятся все необходимые библиотеки:
- `aiogram` - работа с Telegram Bot API
- `aiosqlite` - асинхронная база данных
- `aiohttp` - получение курсов валют
- `python-dotenv` - работа с .env файлом

### 2️⃣ Настройка .env файла

Откройте файл `.env` и заполните:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz    # От @BotFather
ADMIN_ID=123456789                                  # Ваш Telegram ID (@userinfobot)
DATABASE_PATH=data/bot.db
```

### 3️⃣ Запуск

```bash
python bot.py
```

✅ **Готово!** Бот запущен и работает.

## 💡 Важные моменты

### ✅ Что работает автоматически:

- **Курс TON/RUB** - получается через CoinGecko API
- **Все комиссии** - Telegram (7%), Fragment (5%) уже учтены
- **Уведомления** - пользователи получают статусы заявок
- **База данных** - создается автоматически при первом запуске

- **Процент прибыли** (по умолчанию 30%) - `/admin` → Настройки

- **Приветственное сообщение** - текст при /start

## 📊 Как работает расчет

```
Баланс канала (Stars)
    ↓
−7% Telegram (комиссия вывода)
    ↓
−5% Fragment (комиссия конвертации)
    ↓
× 0.01 (Stars → GRAM)
    ↓
× [Актуальный курс TON] (получен через API)
    ↓
−30% (прибыль бота, настраивается)
    ↓
= Итоговая цена для пользователя
```

Пример:
- **Баланс:** 10,000 Stars
- **Курс TON:** 285.50 RUB
- **Результат:** 17,656.75 RUB

## 🔄 Типичный процесс сделки

### 1. Пользователь создает заявку
- Вводит данные канала
- Видит расчет стоимости
- Выбирает метод оплаты

### 2. Админ получает уведомление
- Видит все данные канала
- Принимает решение: купить или отказать

### 3. Если одобрено
- Пользователю отправляется инструкция
- Нужно передать канал админу (бот дает @username)
- Пользователь отправляет реквизиты

### 4. Админ получает реквизиты
- Проверяет передачу канала
- Подтверждает выплату
- Или отказывает (канал не передан / неверные данные)

### 5. Завершение
- Пользователь получает уведомление
- Сделка сохраняется в историю
- Статистика обновляется

## 🌐 О курсах валют

### Откуда берется курс?

Бот автоматически получает актуальный курс TON/RUB через **CoinGecko API**:
- ✅ Бесплатно
- ✅ Без регистрации
- ✅ Обновление при каждом расчете
- ✅ Резервное значение при недоступности

### Что делать если API недоступен?

Бот автоматически использует резервное значение **100 RUB/TON**. В логах увидите сообщение. Когда API заработает, курс снова будет актуальным.

```bash
pkill -f bot.py

# Затем запустите снова
python bot.py
```
