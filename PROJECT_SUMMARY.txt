📋 КРАТКОЕ ОПИСАНИЕ

Полнофункциональный Telegram-бот для автоматизированной скупки каналов
с балансом звезд (Stars). Включает автоматический расчет стоимости,
систему заявок, админ-панель и поддержку.

🚀 БЫСТРЫЙ СТАРТ

1. Установите зависимости:
   pip install -r requirements.txt

2. Настройте .env файл:
   - BOT_TOKEN (от @BotFather)
   - ADMIN_ID (ваш Telegram ID)

3. Проверьте конфигурацию:
   python check_config.py

4. Запустите бота:
   python bot.py

Подробная инструкция: QUICKSTART.md
