📋 ВАМ ОСТАЛОСЬ СДЕЛАТЬ ВСЕГО 4 ШАГА:

┌─────────────────────────────────────────────────────────────────┐
│ ШАГ 1: Создайте бота в Telegram (2 минуты)                     │
└─────────────────────────────────────────────────────────────────┘

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте команду: /newbot
4. Придумайте имя бота (например: "Скупка Каналов")
5. Придумайте username (например: "buy_channels_bot")
6. Скопируйте токен (выглядит так: 123456:ABC-DEF...)

┌─────────────────────────────────────────────────────────────────┐
│ ШАГ 2: Узнайте свой Telegram ID (30 секунд)                    │
└─────────────────────────────────────────────────────────────────┘

1. Откройте @userinfobot в Telegram
2. Нажмите START
3. Скопируйте ваш ID (это число, например: 123456789)

┌─────────────────────────────────────────────────────────────────┐
│ ШАГ 3: Настройте файл .env (1 минута)                          │
└─────────────────────────────────────────────────────────────────┘

1. Откройте файл .env (в папке проекта)
2. Замените "your_bot_token_here" на токен из Шага 1
3. Замените "your_admin_id_here" на ID из Шага 2
4. Сохраните файл

Пример правильного .env:
┌─────────────────────────────────────────────────────────────────┐
│ BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz                 │
│ ADMIN_ID=123456789                                              │
│ DATABASE_PATH=data/bot.db                                       │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ ШАГ 4: Запустите бота (1 минута)                               │
└─────────────────────────────────────────────────────────────────┘

Windows:
  1. Откройте командную строку в папке проекта
  2. Выполните: pip install -r requirements.txt
  3. Выполните: python check_config.py
  4. Если всё ОК, выполните: python bot.py
  
  ИЛИ просто дважды кликните на файл run.bat

Linux/Mac:
  1. Откройте терминал в папке проекта
  2. Выполните: pip3 install -r requirements.txt
  3. Выполните: python3 check_config.py
  4. Если всё ОК, выполните: python3 bot.py
  
  ИЛИ выполните: ./start.sh
