# Бот для скупки Telegram-каналов

Телеграм-бот для автоматизированной скупки каналов с балансом звезд (Stars).

## 🚀 Возможности

### Для пользователей:
- 💰 Продажа каналов с автоматическим расчетом стоимости
- 🌐 **Актуальные курсы в реальном времени** через CoinGecko API
- 📊 Учет всех комиссий (Telegram 7%, Fragment 5%, прибыль 30%)
- 💳 Выбор метода оплаты (RUB, GRAM, Stars)
- 👤 Личный профиль с статистикой
- 💬 Система поддержки с обращениями

### Для администратора:
- 📋 Управление заявками на покупку
- ✅ Одобрение/отклонение заявок
- 💸 Управление выплатами
- 📊 Статистика бота
- 📢 Рассылка сообщений
- ⚙️ Гибкие настройки (курсы, комиссии, тексты)
- 📜 История покупок (купленные/отказанные)
- 🧮 Калькулятор с актуальными курсами

## 📦 Установка

### 1. Установите Python 3.8+

Убедитесь, что у вас установлен Python версии 3.8 или выше.

### 2. Клонируйте или скачайте проект

```bash
cd "c:\Users\SystemX\Desktop\Бот скупка каналов"
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте бота

Откройте файл `.env` и укажите:

```env
BOT_TOKEN=your_bot_token_here      # Токен вашего бота от @BotFather
ADMIN_ID=your_admin_id_here        # Ваш Telegram ID (получить можно у @userinfobot)
DATABASE_PATH=data/bot.db          # Путь к базе данных
```

## 🎯 Запуск

```bash
python bot.py
```

Бот запустится и начнет принимать команды.

## 📖 Использование

### Для пользователей:

1. **Запуск бота** - `/start`
2. **Продать канал** - Нажмите кнопку "💰 Продать канал"

2. **Разделы**:

   - 📊 **Статистика** - статистика бота
   - 📜 **История скупки** - купленные и отказанные каналы
   - ⚙️ **Настройки** - настройка параметров бота

### Настройки бота (в админке):

- **Приветственное сообщение** - текст при /start
- **Процент комиссии** - сколько вычитать в прибыль (по умолчанию 30%)
- **Контакт поддержки** - @username для связи
- **~~Курс GRAM к RUB~~** - ⚠️ **УСТАРЕЛО**: Курс получается автоматически через API
- **~~Курс Stars к GRAM~~** - Фиксированное значение: 0.01 (константа Telegram)
- **~~Комиссия вывода звезд~~** - Фиксированные комиссии: Telegram 7%, Fragment 5%

> 📡 **Новое**: Курс TON/RUB теперь получается автоматически из CoinGecko API при каждом расчете!

## 📐 Алгоритм расчета стоимости (обновлен)

Бот использует 5-шаговый алгоритм расчета:

### Шаг 1: Комиссия Telegram при выводе
```
Stars после Telegram = Общий баланс × (1 - 7%)
```
Telegram берет 7% при выводе Stars с канала.

### Шаг 2: Комиссия Fragment при конвертации
```
Stars после Fragment = Stars после Telegram × (1 - 5%)
```
Fragment берет 5% при конвертации Stars в TON/GRAM.

### Шаг 3: Конвертация Stars → GRAM
```
GRAM = Stars после Fragment × 0.01
```
Фиксированный курс: 1 Star = 0.01 GRAM.

### Шаг 4: Конвертация GRAM → RUB
```
RUB = GRAM × Актуальный курс TON
```
**Курс получается автоматически** через CoinGecko API в реальном времени.

### Шаг 5: Вычет прибыли бота
```
Итоговая цена RUB = RUB × (1 - 30%)
```
Процент прибыли настраивается (по умолчанию 30%).

### Пример расчета:

**Исходные данные:**
- Баланс канала: 10,000 Stars
- Актуальный курс TON: 285.50 RUB (получен через API)
- Процент прибыли: 30%

**Пошаговый расчет:**
1. Telegram (−7%): 10,000 × 0.93 = 9,300 Stars
2. Fragment (−5%): 9,300 × 0.95 = 8,835 Stars
3. Stars → GRAM: 8,835 × 0.01 = 88.35 GRAM
4. GRAM → RUB: 88.35 × 285.50 = 25,223.93 RUB
5. Прибыль (−30%): 25,223.93 × 0.70 = **17,656.75 RUB**

**Итоговая цена для пользователя:**
- 💵 17,656.75 RUB
- 💎 61.845 GRAM
- ⭐ 6,184.5 Stars

## 🔒 Безопасность

- Храните `.env` файл в секрете
- Не публикуйте токен бота и ID администратора
- Регулярно делайте резервные копии базы данных `data/bot.db`

## 🐛 Устранение неполадок

### Бот не запускается
- Проверьте правильность токена в `.env`
- Убедитесь, что установлены все зависимости

### Админ-панель не открывается
- Проверьте правильность ADMIN_ID в `.env`
- Убедитесь, что ID указан без кавычек и символов

### Ошибки при работе с базой данных
- Удалите файл `data/bot.db` и перезапустите бота
- База создастся заново с чистыми таблицами

### Ошибки получения курса
- Проверьте интернет-соединение
- CoinGecko API может быть временно недоступен
- Бот автоматически использует резервное значение (100 RUB/TON)
- Для диагностики см. логи в консоли

## 🌐 API интеграции

Бот использует:
- **CoinGecko API** - бесплатный сервис для получения курсов криптовалют
- Без необходимости регистрации или API ключей
- Лимит: ~10-50 запросов в минуту (достаточно для бота)
- Подробности: [RATES_API.md](RATES_API.md)
