🚀 БЫСТРЫЙ ЗАПУСК
═══════════════════════════════════════════════════════════════
1. pip install -r requirements.txt
2. Настроить .env (токен и ADMIN_ID)
3. python check_config.py
4. python bot.py

💻 КОМАНДЫ ДЛЯ ПОЛЬЗОВАТЕЛЯ
═══════════════════════════════════════════════════════════════
/start          - Запуск бота
Профиль         - Статистика пользователя
Продать канал   - Создать заявку на продажу
Поддержка       - Обратиться в техподдержку

👑 КОМАНДЫ АДМИНИСТРАТОРА
═══════════════════════════════════════════════════════════════
/admin          - Открыть админ-панель
Пользователи    - Список всех пользователей
Рассылка        - Отправить сообщение всем
Заявки          - Управление заявками на покупку
Обращения       - Система поддержки
Статистика      - Общая статистика бота
История         - История покупок/отказов
Настройки       - Изменить параметры бота

📊 НАСТРОЙКИ БОТА (в админке)
═══════════════════════════════════════════════════════════════
- Приветственное сообщение
- Процент комиссии (по умолчанию 30%)
- Комиссия вывода Stars (по умолчанию 7%)
- Курс GRAM к RUB (по умолчанию 100)
- Курс Stars к RUB (по умолчанию 2.5)
- Контакт поддержки

💰 АЛГОРИТМ РАСЧЕТА
═══════════════════════════════════════════════════════════════
1. Доступный баланс = Общий баланс - Холд
2. Stars после вывода = Доступный × (1 - комиссия_вывода)
3. GRAM = Stars × курс_stars_to_gram
4. Рубли = GRAM × курс_gram_to_rub
5. Итоговая цена = Рубли × (1 - процент_прибыли)

🔧 УСТРАНЕНИЕ ПРОБЛЕМ
═══════════════════════════════════════════════════════════════
Проблема: Бот не запускается
Решение: python check_config.py

Проблема: "Module not found"
Решение: pip install -r requirements.txt

Проблема: Ошибка базы данных
Решение: Удалить data/bot.db и перезапустить

Проблема: Нет прав доступа
Решение: Проверить ADMIN_ID в .env
