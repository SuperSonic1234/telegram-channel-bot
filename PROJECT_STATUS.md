## 🔢 Алгоритм расчета

### 5 шагов:
1. **Telegram комиссия:** −7%
2. **Fragment комиссия:** −5%
3. **Stars → GRAM:** ×0.01
4. **GRAM → RUB:** ×актуальный курс (API)
5. **Прибыль:** −30% (настраивается)

### Пример:
```
10,000 Stars
→ 9,300 Stars (−7% Telegram)
→ 8,835 Stars (−5% Fragment)
→ 88.35 GRAM
→ 25,223.93 RUB (курс 285.50)
→ 17,656.75 RUB (−30% прибыль)
```

## 🌐 API интеграции

### CoinGecko API ✅
- **Статус:** Работает
- **Endpoint:** `https://api.coingecko.com/api/v3/simple/price`
- **Параметры:** `ids=the-open-network&vs_currencies=rub`
- **Бесплатно:** Да
- **Регистрация:** Не требуется
- **Лимит:** ~10-50 req/min
- **Fallback:** 100 RUB/TON
